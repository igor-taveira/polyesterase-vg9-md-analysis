# polyesterase-vg9-md-analysis

This repository contains the Python scripts used for molecular dynamics trajectory analysis in the manuscript “Genome Mining and Pangenome Analysis of the Stutzerimonas Genus: a Novel Source of Candidate Polyester-Degrading Enzymes.” The workflows analyze Polyesterase VG-9 complexes with PET oligomers (dimer–pentamer) and PET degradation products (MHET, BHET, TPA, and EG), including RMSD, RMSF, radius of gyration, intermolecular contacts, hydrogen bonds, COM distances, energetic descriptors, PCA, and DCCM analyses.
